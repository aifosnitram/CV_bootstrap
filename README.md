# CV — Bootstrap 5

Class project for the INT module at IES Emili Darder: the wireframe of my CV, laid out with Bootstrap 5.

Two versions of the same page:

- `spanish/` — Spanish, the original wireframe
- `english/` — the same content in English

Each folder is self-contained: open `index.html` and the nav moves between pages. Bootstrap comes from the CDN, the photo and stylesheet from `assets/`.

Requirement for this deliverable: the CV has to open on any phone, so it is published with GitHub Pages rather than handed in as local files.
